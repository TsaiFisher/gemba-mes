# R31 baseline — 空的，且應該維持是空的。
#
# R31 對帳的是「手機畫面」與「有沒有一頁手冊在講它」。新增一個手機畫面時，
# 修法只有兩種，成本都是分鐘級：
#   1. 這一頁使用者會操作 → 在 wwwroot/docs/user/mobile/ 寫一頁，
#      doc-header 寫上「路徑：/mobile/…」，並掛進 index.html 的側欄；
#   2. 這一頁不是操作畫面（登入殼、轉址殼、共用子頁、模組入口清單）
#      → 加進 ConventionTests.MobilePagesWithoutOwnManualPage 並寫下理由。
#
# 兩種都不是「之後再說」，所以這裡不該長出任何一行。
# 把違規寫進 baseline 等於決定「這個畫面永遠不寫手冊」——
# 那個決定應該寫在例外清單裡、附上理由，讓下一個人看得到，而不是藏在這個檔案裡。
