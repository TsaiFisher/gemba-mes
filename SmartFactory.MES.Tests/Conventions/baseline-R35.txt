# R35 baseline — 空的，且應該維持是空的。
#
# R35 對帳的是「來源待決項（`<!-- open-items -->`）」與「手抄聚合節
# （`<!-- mirrors -->`，目前是 manual-test-plan.md §12〈未完成事項總表〉）」。
# 出現違規時，修法只有一種，成本是秒級——**改那一列**：
#   1. 來源已結案、聚合節還開著 → 在聚合節那一列補 `~~` 或 ✅
#      （理由留在來源，不要搬過來；§12 是索引不是內容）；
#   2. 來源還開著、聚合節已劃掉 → 先在來源結案再劃這裡，
#      否則缺口會被「看起來已完成」蓋住；
#   3. 來源開著、聚合節根本沒列 → 補一列（第一欄寫編號，
#      或在出處欄寫 `§11 #N`）。
#   4. 這一項是刻意延後的 → 在**來源**標 `⏸`，R35 會跳過它。
#
# 沒有第五種。把違規寫進 baseline 等於決定「這條缺口容許在總表上消失」，
# 而那正是這條規則存在的理由：§12.3 與 §12.8 都自己寫下了
# 「R29 對不到這裡」「這裡不會自動跟著變」，然後繼續靠人記得——
# 一旦這個檔案長出行來，就等於把那句話又寫了一遍。
