在製品報表WIP Report

路由：/WipReport  |  在製品數量與金額（WIP）Route: /WipReport  |  WIP quantity and value

列出各工單目前在製數量與在製成本（已投入 − 已繳庫），月結時以 WIP 快照留存，供成本結帳與存貨評價。Lists the WIP quantity and WIP cost of each work order (put in − received), kept as a WIP snapshot at month end for cost closing and inventory valuation.
