機台停機分析Machine Downtime

路由：/MachineDowntime  |  停機時數統計（計畫/非計畫、原因別）Route: /MachineDowntime  |  Downtime hour statistics (planned / unplanned, by reason)

彙總計劃停機與機台狀態異動的停機時數，依原因別、機台別統計排名，作為設備保養改善依據。Aggregates downtime hours from planned downtime and machine status changes and ranks them by reason and machine, as input to maintenance improvement.

機台停機分析畫面截圖（示意，實際欄位/資料依權限與查詢條件而異）Machine downtime analysis screenshot (illustrative; actual fields and data vary by permission and query criteria)

查詢Search

1
查詢列輸入條件後點「查詢」；欄位標題可點擊排序，清單下方有分頁導航。Enter your criteria on the query bar and click "Search"; column headers can be clicked to sort, and the paging controls sit below the list.
