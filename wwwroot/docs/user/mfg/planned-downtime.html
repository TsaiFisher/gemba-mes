計劃停機Planned Downtime

路由：/PlannedDowntime  |  機台計畫性停機（保養/歲修）登記Route: /PlannedDowntime  |  Recording planned machine downtime (maintenance / annual overhaul)

登記機台的計畫性停機時段（保養、歲修、教育訓練等）。排程引擎會避開停機時段，稼動率與 OEE 計算也會將計畫停機自可用時間中扣除。Records planned downtime for a machine (maintenance, annual overhaul, training …). The scheduler works around it, and utilisation and OEE deduct planned downtime from the available time.

計劃停機畫面截圖（示意，實際欄位/資料依權限與查詢條件而異）Planned downtime screenshot (illustrative; actual fields and data vary by permission and query criteria)

查詢Search

1
查詢列輸入條件後點「查詢」；欄位標題可點擊排序，清單下方有分頁導航。Enter your criteria on the query bar and click "Search"; column headers can be clicked to sort, and the paging controls sit below the list.

作業流程Process

登記停機Record downtime

1
點「新增」，選擇機台（工作中心）與停機起訖時間。Click "Add", then choose the machine (work center) and the start and end of the downtime.
2
選擇停機類別並填寫說明後儲存。Choose the downtime category, add a description and save.
