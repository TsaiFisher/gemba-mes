基本資料維護（BAS）Basic Data (BAS)

系統各模組共用的主檔資料，須在使用前完成設定Master data shared by every module; complete it before use

BAS（Basic Data）模組包含所有跨模組共用的主檔與設定，例如廠商、產品、倉庫、計量單位等。這些資料是採購、庫存、製造各模組正常運作的基礎，建議依以下優先順序完成初始設定。The BAS (Basic Data) module holds every master record and setting shared across modules — suppliers, products, warehouses, units of measure and so on. This data is the foundation on which purchasing, inventory and manufacturing operate, so complete the initial setup in the order below.

建議設定順序Recommended setup order

  1. 幣別主檔（Currency）Currency Master
  2. 稅別（Tax）Tax
  3. 計量單位（Uom）Unit of Measure
  4. 倉庫（Warehouse）Warehouse
  5. 產品類別（ProductCategory）Product Category
  6. 產品主檔（Product）Product Master
  7. 公司/廠商主檔（Company）Company / Vendor Master
  8. 班別（Shift）→ 班別群組（ShiftGroup）→ 特殊日（SpecialDay）Shift → Shift Group → Special Day
  9. 工作中心（WorkCenter）Work Center
  10. 單號設定（DocNumberConfig）Doc Number Config

幣別、稅別、計量單位、產品與往來廠商為全公司共用（不分廠別）；倉庫、工作中心、班別、單號設定屬各廠獨立維護。Currencies, tax codes, units of measure, products and business partners are shared company-wide (no plant split); warehouses, work centers, shifts and doc number configs are maintained per plant.

畫面清單Screen list

公司/廠商主檔Company / Vendor Master
客戶、廠商、公司資料維護；含聯絡人管理、有簽核流程Customer, supplier and company data, including contacts; goes through approval
幣別主檔Currency Master
幣別代碼與匯率維護，含每日買/賣匯率記錄Currency codes and exchange rates, including daily buy/sell rates
產品主檔Product Master
產品基本資料、計量單位、成本、MRP 參數；有簽核流程Product basics, unit of measure, cost and MRP parameters; goes through approval
產品類別Product Category
產品分類維護，可設定預設倉庫、儲位與計量單位Product category maintenance, with default warehouse, location and unit of measure
倉庫Warehouse
倉庫與儲位管理，含 MRP 倉、倉庫類型設定Warehouse and location management, including the MRP warehouse flag and warehouse type
工作中心Work Center
工作站與機台管理，含工時費率、班別群組設定Work station and machine management, including hourly rates and shift groups
計量單位Unit of Measure
計量單位維護，含單位間換算率設定Unit of measure maintenance, including conversion ratios between units
稅別Tax
稅率代碼維護，供採購與銷售模組選用Tax rate codes for use in purchasing and sales
班別Shift
日班/夜班等班別定義，含可用工時分鐘數Shift definitions such as day and night, with the available work minutes
班別群組Shift Group
每週各日班別組合設定，供工作中心排程使用Weekly shift combination used by work center scheduling
特殊日Special Day
假日與補班日設定，月曆視圖管理Holiday and compensatory workday setup with a calendar view
單號設定Doc Number Config
各類單據的單號格式（前置碼、日期、序號）設定Document number format (prefix, date, sequence) for each document type
各廠參數覆寫一覽Plant Parameter Overview
唯讀報表：一次看完各廠系統參數的覆寫值與繼承狀態（選單位於「管理系統」）Read-only report showing each plant’s parameter overrides and inherited values side by side (found under Admin Management in the menu)
模具Tooling
生產用模具主檔，含規格、模穴數、類型Production tooling master with specification, cavity count and type
容器主檔Container Master
包裝容器類型維護（棧板、紙箱等）Packaging container types (pallets, cartons and so on)
箱子（容器個體）Boxes (Container Units)
重複使用的實體箱子：固定 QR 標籤、目前內容與歷程Reusable physical boxes: fixed QR labels, current contents and history
庫存異動類型Inventory Transaction Type
庫存進出類型代碼維護，控制批號與單據需求Stock in/out type codes, controlling lot and source-document requirements
