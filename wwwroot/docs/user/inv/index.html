庫存管理（INV）Inventory Management (INV)

倉儲三層結構（倉庫/儲位/批號）、各式庫存單據、倉庫作業與庫存分析The three-level storage structure (warehouse / location / lot), the inventory documents, warehouse operations and inventory analysis

INV（Inventory）模組是全系統庫存帳的核心：所有進出異動皆以「單據 → 倉庫作業 → 過帳」產生庫存異動（StockMovement）並即時更新庫存餘額與移動平均成本（AVCO；批號管制品可用 FIFO 成本層）。單據採三層結構（表頭/明細行/儲位明細），業務確認與倉庫執行分權：倉庫在「倉庫作業」逐儲位執行，全部完成後單據自動過帳。模組亦涵蓋調撥、盤點、報廢、借出、樣品、委外/重工發退料、跨廠調撥與多種庫存分析報表。The INV (Inventory) module is the core of the stock ledger: every movement is produced through "document → warehouse operation → posting", which writes a stock movement and updates the balance and moving average cost (AVCO; lot-controlled items can use FIFO cost layers) immediately. Documents have three levels (header / line / location detail), separating business confirmation from warehouse execution: the warehouse works location by location under Warehouse Operations, and the document posts automatically once everything is done. The module also covers transfers, stock counts, scrap, loans, samples, outsource and rework material, cross-plant transfers and a range of inventory analysis reports.

使用注意Points to note

  1. 出庫以「儲位可用量」檢核（在庫 − 預留），不足擋單。Issues are checked against the available quantity of the location (on hand − reserved) and blocked when it is insufficient.
  2. 過帳受「會計期間鎖」管制，已關帳期間的異動會被擋下。Posting is subject to the accounting period lock; movements in a closed period are blocked.
  3. 已有庫存異動的單據不可業務撤回，只能作廢沖銷。A document that has already moved stock cannot be withdrawn by the business side; it can only be voided and reversed.
  4. 入庫單的貨已被後續出庫用掉時，不能直接作廢（2026-10-21 起）：FIFO 料是那一批已被扣用；移動平均料是作廢後剛好收光、但帳上剩的價值與要收回的對不上。請先作廢用掉它的出庫單，或改用進貨退出／庫存調整。直接作廢會讓總帳存貨與庫存明細帳的金額從此對不上。A receipt whose goods have already been used by later issues cannot be voided directly (from 21 October 2026): for FIFO items, that batch has been consumed; for moving-average items, the void would empty the stock while the value left on the books does not match what would be reversed. Void the issues that used it first, or use a purchase return or stock adjustment instead. Voiding it directly would leave the general-ledger inventory and the stock ledger permanently out of step.
  5. 同一張單已作廢過時再按一次作廢，不會有任何變動。Voiding a document that has already been voided changes nothing.
