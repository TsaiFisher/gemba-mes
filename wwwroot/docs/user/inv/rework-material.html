重工發退料單Rework Material

路由：/ReworkMaterial  |  未開工單的重工發料/退料Route: /ReworkMaterial  |  Material issue and return for rework without a work order

供沒有開重工工單的現場重工領用料件與退回餘料（例如在工作中心直接修整），流程同一般發退料：發料在倉庫作業下架時過帳、退料在上架時過帳。Issues material to, and takes surplus back from, rework done without a rework work order (for example touch-up done directly at a work center). The flow is the same as an ordinary issue and return: an issue posts when it is picked in Warehouse Operations, a return when it is put away.

有開重工工單的重工請改用「工單發退料單」的重工發料／重工退料。那邊會回寫工單用料的已發／已退量，料進出在製品，完工入庫時結算：良品以不良品原值回存貨，重工多花的用料、人工、製費轉「5250 重工損失」。本單的「工單」欄填了既有的工單號會被擋下。For rework with a rework work order, use Rework Issue / Rework Return on the Work Order Material Slip instead. That updates the work order's issued / returned quantities; the material moves in and out of work in process and is settled at completion: good units go back to inventory at the defective items' original value, and the extra material, labor and overhead spent on the rework go to "5250 Rework Loss". Entering an existing work order number in this document's "Work order" field is rejected.

作業流程Process

建立重工發/退料單Create rework issue / return

1
點「新增」開啟側欄，填寫重工發/退料單表頭與明細行後儲存（草稿）。Click "Add" to open the panel, fill in the rework issue / return header and lines, then save (as a draft).
2
點「送審」進入簽核流程；核准後單據自動轉「已確認」。若免簽核，直接點「確認」。Click "Submit" to start the approval flow; the document turns to "Confirmed" once approved. Where no approval is required, click "Confirm" directly.

後續作業Follow-up actions

1
已確認/已過帳單據可點「列印」產生含 QR Code 的正式表單（新分頁開啟）。Confirmed and posted documents can be printed with "Print", producing the official form with a QR code in a new tab.
2
已過帳單據如需沖銷，點「作廢」並填寫原因；系統產生反向庫存/帳務異動。To reverse a posted document, click "Void" and enter a reason; the system creates the reversing stock and accounting entries.
重工退料（RR）以所選來源重工領料行的實際出庫成本入庫，明細上填的單價不影響存貨成本；重工損失照同一金額沖回。A rework return (RR) comes back at the actual issue cost of the selected rework issue line; the unit price entered on the line does not change inventory cost. Rework loss is reversed by the same amount.
