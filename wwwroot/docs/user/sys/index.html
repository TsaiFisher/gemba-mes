系統管理System Administration

使用者、角色、權限、組織與廠別等全公司共用的設定，由系統管理員統一維護Company-wide settings — users, roles, permissions, organization and plants — maintained centrally by the system administrator

系統管理的畫面決定The system administration screens decide 誰能用這套系統、能用到什麼程度who may use the system and how far they may go。設定的先後順序是：. The order to set things up in is: 廠別 → 組織架構 → 角色 → 功能權限 → 使用者plants, organization structure, roles, permissions, then users，倒過來做會卡住（例如角色還沒有權限，指派給人也看不到任何畫面）。; doing it the other way round gets stuck — a role with no permissions shows the person nothing, however it is assigned.

部分畫面只限 Admin：Some screens are for Admin only:使用者、角色、組織架構、廠別、權限設定、手機權限、兩步驟驗證重置與授權狀態，只在目前身份為 Admin 時出現在選單、也才進得去（不由權限矩陣決定）。代碼維護、稽核紀錄與系統參數依權限矩陣的勾選。 users, roles, organization, plants, permission settings, mobile permissions, two-step verification reset and license status appear in the menu and open only while your current role is Admin (the permission matrix does not decide them). Code maintenance, the audit log and system parameters follow the permission matrix.

使用者管理User Management

登入帳號、Email、語系，以及每個人被指派了哪些角色。Sign-in accounts, e-mail, language, and which roles each person holds.

角色管理Role Management

權限的載體：角色名稱、所屬組織單位、可用廠別與預設廠。The carrier of permissions: the role name, its organization unit, the plants allowed and the default plant.

組織架構Organization Structure

部門樹、上下層關係與廠別繼承；主管簽核沿著它往上找人。The department tree, its levels and plant inheritance; supervisor approval walks up it to find the approver.

廠別管理Plant Management

廠別代碼、預設語系與時區，以及單一廠的系統參數覆寫。Plant codes, default language and time zone, and per-plant overrides of the system parameters.

功能權限設定Permission Settings

以角色為單位的權限矩陣：讀取／新增／修改／刪除／列印。The permission matrix, role by role: read, create, update, delete and print.

手機模組權限Mobile Module Permissions

手機端（PWA）現場作業的逐一動作授權，與桌面版權限各自獨立。Action-by-action permissions for shop-floor work in the mobile app, independent of the desktop matrix.

稽核日誌Audit Log

誰在什麼時候改了哪一筆資料，以及變更前後的內容。Who changed which record and when, and what the values were before and after.

兩階段驗證重置Two-Factor Reset

使用者遺失驗證器時，由管理員重置其兩階段驗證。Resetting two-factor authentication for a user who has lost their authenticator.

授權狀態License Status

授權是否有效；申請、換發、匯入授權與每 90 天的授權確認（網址 /License）。Whether the license is valid; applying for, renewing and importing a license, and the 90-day confirmation (address /License).

代碼維護Code Maintenance

各主檔下拉選單的選項來源：收款方式、庫存模式、儲位類型等。Where the options in master-data drop-downs come from: payment type, stock mode, location type and more.

系統參數System Parameters

庫存／製造簡化模式、預設計價方式、本位幣、供應商評分卡權重。Simplified inventory and manufacturing modes, the default costing method, the local currency and the supplier scorecard weights.

各廠參數覆寫一覽Plant Parameter Overview

唯讀：一次看完各廠改過哪些系統參數、哪些廠沿用全域值。Read-only: see at a glance which plants override which system parameters and which follow the global value.

個人設定Personal Settings

每個人自己的畫面：切換目前廠別與身份、設定個人時區。Each person's own screen: switch the current plant and role, and set a personal time zone.
