授權狀態License Status

選單位置：管理系統 → 授權狀態（網址 /License）  |  權限：選單入口與各項操作限目前身份為 Admin；狀態本身人人可看Menu: System Administration → License Status (address /License)  |  Permission: the menu entry and every action require the current role to be Admin; anyone may view the status itself

授權狀態頁顯示本系統目前的授權是否有效，並提供The license status page shows whether this system's license is currently valid, and is where you 申請、換發、匯入授權與定期確認授權apply for, renew, import and periodically confirm the license的入口。安裝後第一次確認授權、換電腦或主機板、虛擬機每 90 天的確認，都在這一頁完成。. Checking the license after installation, moving to a new computer or motherboard, and the 90-day confirmation on a virtual machine all happen on this page.

找不到入口時：If you cannot find the way in:直接在網址列輸入 type /License（例如 after the site address (for example https://localhost:7054/License）。授權有狀況時，畫面上方的提示條也會連到這一頁；授權不屬於這台電腦時，系統只會顯示這一頁。). When something is wrong with the license, the notice bar at the top of every screen links here too; if the license does not belong to this computer, this is the only page the system shows.

畫面內容What the page shows

區塊Section說明Guide
狀態（彩色框）Status (coloured box)綠色「授權有效」並說明綁定與效期（例如「已綁定本機，永久有效」）；黃色「授權有事項需要處理」列出待辦（例如即將到期、尚未確認）；紅色「唯讀」或「已停用」說明原因與停用日期。Green "License valid", with a line on binding and term (for example "Bound to this machine; No expiry date"); amber "The license needs attention" lists what to do (expiring soon, not yet confirmed); red "Read-only" or "Disabled" gives the reason and the date the system stops.
到期日／唯讀起始／停用日Expiry / read-only since / disabled on永久授權的到期日顯示「永久」。唯讀起始與停用日只在授權失效時出現。A perpetual license shows "Perpetual" as its expiry. Read-only since and disabled on appear only once the license has lapsed.
授權編號、授權對象、綁定方式、座數License ID, licensee, binding, seats只有 Admin 看得到。換發或聯絡授權提供者時用得到授權編號。Visible to Admin only. You need the license ID when renewing or contacting the license provider.
申請或換發授權Apply for or renew a license顯示部署類型、主機比對結果與申請碼。「申請授權」開啟登記頁；「申請換發」用於換電腦、換主機板。申請時只送出指紋與主機識別碼（皆為雜湊）。Shows the deployment type, the host check result and the request code. "Apply for a license" opens the registration page; "Request renewal" is for a new computer or motherboard. Only the fingerprint and host identifier (both hashed) are sent.
授權確認（每 90 天）License confirmation (every 90 days)虛擬機，或已啟用線上授權確認時才需要。按「確認授權」會開啟授權伺服器的確認頁，完成後自動回到本頁；這台電腦不能上網時，可把確認連結傳到其他裝置，再「匯入確認回覆」。Needed only on a virtual machine, or once online license check is turned on. "Confirm license" opens the license server's confirmation page and comes back here when done; if this computer cannot reach the internet, send the link to another device and then use "Import confirmation reply".
線上授權確認Online license check綁定本機的授權可自行啟用：啟用後每 90 天確認一次，整台複製到別處的副本無法通過。虛擬機一律強制啟用，無法停用。A machine-bound license may turn this on: it then needs confirming every 90 days, and a copy of the whole machine elsewhere cannot pass. On a virtual machine it is always on and cannot be turned off.
匯入授權檔Import license file上傳收到的 license.json。系統先驗證，通過才取代現行授權（舊檔自動備份），不需重新啟動。Upload the license.json you received. It is verified first and replaces the current license only if it passes (the old file is backed up); no restart is needed.
不要編輯授權檔：Do not edit the license file:所有欄位都在簽章內，改了就是「簽章無效」。主機比對顯示「不符」時代表授權不屬於這台電腦，請用頁上的申請碼重新申請。 every field is covered by the signature, so any change makes it "signature invalid". If the host check says the license does not belong to this computer, apply again with the request code on the page.
