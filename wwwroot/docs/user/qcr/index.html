品質管理（QCR）Quality Control (QCR)

IQC/IPQC/FQC 檢驗、NCR 不合格品處置、儀器校正與 SPC 製程能力IQC/IPQC/FQC inspection, NCR disposition, instrument calibration and SPC process capability

QCR（Quality Control）模組管理三段檢驗與不合格品閉環：IQC 進料檢驗（進貨/委外收貨觸發，MIL-STD-1916 抽樣、VL 切換與跳批）、IPQC 製程檢驗（工序旗標觸發）與 FQC 完工檢驗（完工入庫硬閘口）。檢驗不合格開立 NCR，處置（報廢/重工/特採/退貨）直接連動對應單據。另含檢驗規範、不良項目代碼、儀器校正管理與 SPC 製程能力分析。The QCR (Quality Control) module manages the three inspection stages and closes the loop on nonconforming material: IQC incoming inspection (triggered by a goods receipt or an outsource receipt, with MIL-STD-1916 sampling, VL switching and skip-lot), IPQC in-process inspection (triggered by an operation flag) and FQC final inspection (a hard gate on completion receipt). A failed inspection raises an NCR whose disposition (scrap / rework / use-as-is / return) drives the matching document directly. The module also covers inspection specs, defect codes, instrument calibration and SPC process capability analysis.
