簽核管理Approval Management

單據的送審、簽核與退回，以及決定哪些單據要簽、由誰簽的設定Submitting, approving and returning documents, and the settings that decide which documents need signing and by whom

簽核由三個部分組成，設定的順序是Approval has three parts, and the order to set them up in is 先建模板、再綁作業類型、最後才有單可簽first the template, then the document type it is attached to, and only then are there requests to sign：:

1
簽核模板The approval template定義一條路線由哪些步驟、哪些簽核人組成。 defines the steps of a route and who signs each one.
2
作業類型簽核設定The document approval setting決定哪一種單據要走哪一條路線——沒設定的單據不送審，存檔即生效。 decides which kind of document follows which route; a type that is not set up is never submitted and takes effect on save.
3
待我簽核My Pending Approvals是簽核者每天實際使用的清單；管理者則從「所有簽核記錄」綜覽與救援卡住的單。 is the list approvers use day to day, while managers oversee everything — and rescue stuck requests — from "All Approval Requests".
簽核設定是分廠的：Approval settings are per plant:作業類型簽核設定只對建立當下所在的廠生效。多廠都要簽核，就得切換到每一廠各設定一次。 a document approval setting applies only to the plant you were in when you created it. If several plants need approval, switch to each and set it up there.

待我簽核／所有簽核記錄My Pending / All Approval Requests

簽核、拒絕、退回修改、查歷程、撤回申請、代理人設定，以及管理者的重新指派。Approving, rejecting, returning for revision, viewing the history, withdrawing a request, setting a delegate, and reassigning as a manager.

簽核模板設定Approval Template Settings

一條簽核路線由哪些步驟組成：主管、指定角色或指定人員，以及自動跳簽。What steps make up an approval route: supervisor, a named role or a named person, plus skipping a repeated approver.

作業類型簽核設定Document Approval Settings

哪一種單據需要簽核、走哪一份模板；設定分廠獨立。Which kinds of document need approval and which template they follow; the settings are per plant.
簽核路線取決於組織架構與角色設定，相關說明見Approval routes depend on the organization structure and the roles, which are covered under 系統管理（SYS）System Administration (SYS)。.
