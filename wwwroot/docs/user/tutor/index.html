操作教學Guided tutorials

依系統的作業程序逐步演示：一條課程走完一段跨畫面的完整流程Step through the system's operating procedures: one course walks one complete cross-screen flow

每一條課程就是手冊裡的一條作業流程。播放時會依序帶您走過流程上的每一個畫面，顯示該畫面的截圖與逐步操作說明，並可開啟語音朗讀。教學內容全部取自使用手冊本身，不是另寫的一份——手冊更新，教學跟著更新。Each course is one of the process flows in this manual. Playing a course walks you through every screen on that flow in order, showing the screenshot and the step-by-step instructions for it, with optional voice narration. All of the content comes from the user manual itself rather than from a separate copy, so when the manual is updated the tutorials follow.

教學是模擬演示，不會動到真實資料。The tutorials are simulated demonstrations and never touch real data. 演示用的是手冊既有的畫面截圖，不會開啟真正的作業畫面，也不會建立、修改或刪除任何單據。要實際操作請從系統選單進入該畫面。They use the screenshots already in the manual; no real screen is opened and no document is created, changed or deleted. To do the work for real, open the screen from the system menu.
流程上標示為外部事件的環節（例如「廠商交貨」）在系統裡沒有對應畫面，播放時會顯示為說明卡片。標示為「替代路徑」的課程是同一段流程的另一種走法（例如簡化模式）。Steps marked as an external event ("supplier delivers", for example) have no screen in the system and are shown as an explanatory card. A course marked "Alternative" is another way through the same stretch of the flow, such as simplified mode.
