上線設定清單

系統管理手冊附件  |  請在上線前逐項完成並核對
本文件目的
列出 SmartFactory MES 上線前必須完成的所有設定項目，特別是「代碼維護」類別， 這些類別的代碼值是各畫面下拉選單的資料來源，未設定將導致使用者無法選擇對應欄位。

1. 基礎架構確認

授權相關項目有先後順序：授權綁定這台主機的「環境指紋」（由機器錨定碼算出）與主機板識別碼。 必須先在正式主機產生錨定碼（Linux 另需完成服務檔設定），再以 SmartFactory.MES.MachineId 取得申請碼申請授權（全新安裝還沒有授權時系統無法啟動，開不了「授權狀態」頁）； 順序顛倒會拿到一張在這台主機上無效的授權。詳見授權與防複製。

2. 代碼維護設定

路由：基本資料 > 代碼維護（/BAS/CodeEntry）

以下各 Category 必須在上線前建立至少一筆代碼，否則對應畫面的下拉選單為空， 使用者無法填寫必填欄位。

操作方式：進入「代碼維護」→ 選擇 Category → 點「新增」→ 填入代碼（Code）、中文名稱、英文名稱、排序 → 儲存。

BAS 基本資料模組代碼

Category 代碼 使用畫面 欄位名稱 說明 / 建議值
payment_type 必填 廠商維護
/BAS/Company		 付款方式 採購付款條件。
建議值：
  • Code: CASH，名稱：現金付款
  • Code: M30，名稱：月結30天
  • Code: M60，名稱：月結60天
  • Code: M90，名稱：月結90天
stock_mode 必填 產品維護
/BAS/Product		 庫存模式 產品的成本計算方式。
建議值：
  • Code: FIFO，名稱：先進先出法
  • Code: MA，名稱：移動平均法
注意：產品建立後此欄位不建議變更，以免成本層計算異常。
tooling_type 選填 工具維護
/BAS/Tooling		 工具類別 生產工具的分類。
建議值：
  • Code: JIG，名稱：治具
  • Code: MOLD，名稱：模具
  • Code: TOOL，名稱：刀具
  • Code: FIXTURE，名稱：夾具

Category 代碼 使用畫面 欄位名稱 說明 / 建議值

  • Code: LOSS，名稱：自然耗損
  • Code: CORRECT，名稱：帳務修正

3. 主檔資料建置

請依下表順序建立主檔（有相依關係，順序不可顛倒）：

#主檔名稱路由必要說明
1計量單位/BAS/Uom所有品項必須有 UOM必填
2幣別/BAS/Currency需設定本位幣（IsBase=true）必填
3稅別/BAS/Tax採購 / 銷售發票稅率必填
4產品類別/BAS/ProductCategory含成本方法設定必填
5產品主檔/BAS/Product含 BOM、庫存模式必填
6廠商 / 客戶/BAS/Company供應商與客戶可同表必填
7倉庫/BAS/Warehouse含倉庫類型設定必填
8儲位/BAS/StorageLocation依倉庫建立儲位選填
9工作中心/BAS/WorkCenterMFG 模組所需選填
10班別 / 班制/BAS/ShiftMFG 排程所需選填

8. UAT 使用者驗收測試

上線前請由各部門代表依下列情境測試：

測試情境模組結果
完整採購流程：請購 → 採購 → 進貨 → 庫存入帳PUR + INV
完整銷售流程：訂單 → 出貨 → 庫存出帳ORD + INV
MRP 執行後工單自動產生MFG
工單領料 → 完工入庫MFG + INV
盤點作業：建立 → 實盤 → 結帳INV
線上簽核：送審 → 核准 → 退回測試全模組
權限測試：確認各角色只能看到對應功能系統管理
待我簽核清單可正確點擊查閱單據簽核管理
所有項目確認完成後，系統即可正式上線。建議保留此清單作為上線紀錄。
